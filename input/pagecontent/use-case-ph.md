Clinical Quality Language has been in use for many years as part of the structured, computable representation of public health reporting rules. In particular, the logic involved in determining reportability of an event, as well as potentially the logic involved in determining applicability and routing of reportable events. For more details on this use case, see the following implementation guides:

* [US Public Health Profiles](http://hl7.org/fhir/us/ph-library): Common architecture and content profiles for use in public health use cases
* [electronic Case Reporting](http://hl7.org/fhir/us/ecr): electronic Case Reporting specifications and transactions

Public health case reporting specifications for use in the US Realm can make use of content from this implementation guide as these patterns and libraries are refined through implementation experience.
